# Python Practice Task: Random Meal Menu Generator

## Task Description

Create a Python program that generates a random daily menu consisting of breakfast, lunch, and dinner. The menu should change every time the program is executed.

### Requirements

1. Create five constants for breakfast items.
2. Create five constants for lunch items.
3. Create five constants for dinner items.
4. Assign a unique numerical value to each food item using the `random` module.
5. Generate a random integer to select one item from each meal category.
6. Display the randomly selected breakfast, lunch, and dinner items.

### Example Items

Breakfast

- Idli
- Dosa
- Poha
- Upma
- Bread Omelette

Lunch

- Veg Biryani
- Chicken Biryani
- Dal Rice
- Fried Rice
- Chapati

Dinner

- Roti with Curry
- Paneer Rice
- Chicken Curry
- Pulao
- Curd Rice

### Sample Output

```
========== RANDOM MENU GENERATOR ==========

Breakfast: Dosa
Lunch: Chicken Biryani
Dinner: Curd Rice

===========================================
```

Another execution might produce:

```
========== RANDOM MENU GENERATOR ==========

Breakfast: Poha
Lunch: Dal Rice
Dinner: Pulao

===========================================
```
